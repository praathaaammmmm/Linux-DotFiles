# 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/dotfiles.git
cd dotfiles
```

Copy the desired configuration files:

```bash
cp -r hypr ~/.config/
cp -r waybar ~/.config/
cp -r kitty ~/.config/
cp -r wofi ~/.config/
```

Restart Hyprland or reboot.

---

# 📦 Dependencies

Install the core packages:

```bash
sudo pacman -S \

wofi \

playerctl \
pipewire \
wireplumber \
networkmanager \
network-manager-applet \
blueman \
ttf-jetbrains-mono-nerd
```

# 🎯 Philosophy

This setup is built around three principles:

- **Minimalism** — remove unnecessary distractions.
- **Productivity** — optimize for software development.
- **Consistency** — maintain a cohesive visual design across the desktop.

Every component is configured to feel lightweight, functional, and visually consistent.
